# Madrid Live — Vercel

موقع متابعة مباريات ريال مدريد والدوري الإسباني والإنكليزي ودوري أبطال أوروبا.

## النشر على Vercel بدون Render

1. ارفع المشروع إلى مستودع GitHub شخصي.
2. افتح Vercel وسجّل الدخول بحساب GitHub.
3. اختر **Add New → Project** ثم اختر المستودع.
4. اترك Build Command وOutput Directory كما هي.
5. اضغط Deploy.

لا توجد متغيرات API أو API_KEY مطلوبة.

## التشغيل المحلي (اختياري)

```bash
npm install
npm start
```

ثم افتح http://localhost:3000
